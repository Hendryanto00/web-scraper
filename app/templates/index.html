PALING MUDAH
Publik, tanpa login
Halaman dapat dibuka tanpa akun dan datanya tersedia dalam HTML awal.
  • Tidak memerlukan konfigurasi .env.
  • Cocok untuk artikel, teks, dan tabel HTML publik.
  • Tidak menjalankan JavaScript atau membaca PDF.
Buka proses scraping


LOGIN OTOMATIS
Login situs
Situs memakai formulir username dan password satu tahap, tanpa CAPTCHA.
  • Isi URL login dan kredensial di .env.
  • Halaman login dan data harus satu domain HTTPS.
  • Selector CSS dapat disesuaikan jika kolom tidak terdeteksi.
Lihat contoh konfigurasi
SCRAPER_LOGIN_URL='https://accounts.example.com/login'
SCRAPER_USERNAME='your-username'
SCRAPER_PASSWORD='your-password'
Salin .env.example menjadi .env. Gunakan akun yang memiliki izin akses.


CAPTCHA / LOGIN BERTAHAP
Login manual
Anda menyelesaikan login sendiri di jendela Chromium yang dibuka aplikasi.
  • Isi SCRAPER_LOGIN_URL di .env; akun di .env tidak wajib.
  • Selesaikan login dan CAPTCHA, lalu klik Sudah login, ambil data.
  • Batas waktu 5 menit. Login lintas domain belum didukung.
Jendela login terbuka di komputer yang menjalankan server.




Apa yang tersimpan?
Browser menyimpan hasil aktif, catatan pemeriksaan, dan metadata 20 proses terakhir dalam sesi. Riwayat bukan arsip hasil lama. Ekspor mengikuti pencarian dan filter pada tabel aktif.


Ada kendala? Mulai dari sini.
Klik pertanyaan untuk melihat langkah penyelesaiannya.




Hasil tidak memiliki tabel
Coba tab Teks atau Tautan. Halaman mungkin memang tidak memiliki tabel HTML. Jika tabel muncul setelah JavaScript berjalan, gunakan mode login yang sesuai. PDF belum didukung.


Login gagal atau kolom tidak ditemukan
Periksa URL login, username, dan password di .env. Sesuaikan SCRAPER_USERNAME_SELECTOR, SCRAPER_PASSWORD_SELECTOR, atau SCRAPER_SUBMIT_SELECTOR bila perlu. Untuk CAPTCHA atau login bertahap, pilih Login manual.


Situs menampilkan HTTP 403, 404, atau 429
403: periksa izin akses. 404: periksa URL halaman. 429: tunggu sebelum mencoba kembali karena situs membatasi permintaan.


Server tidak terbuka atau port sudah dipakai
Pastikan terminal server tetap berjalan. Jika port 8000 terpakai, tambahkan --port 8001 pada perintah Uvicorn, lalu buka http://127.0.0.1:8001.


Bagaimana cara memeriksa dan mengekspor baris?
Buka Verifikasi data, klik detail baris, lalu tandai Sudah diperiksa atau Perlu perbaikan. Untuk Excel, atur pencarian dan filter, klik Ekspor Excel, pilih kolom, lalu unduh file .xlsx.


Ingin menggunakan API langsung?
Buka /docs dan pilih POST /scrape. Coba JSON berikut untuk mode publik.
{"url":"https://example.com","auth_mode":"public"}
