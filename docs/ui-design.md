# Catatan UI

Dashboard menyediakan navigasi ke proses scraping, data hasil scraping, riwayat, pemeriksaan manual, pengaturan, dan panduan. Tabel mengikuti struktur HTML sumber, tanpa asumsi skema khusus.

Mode publik membaca HTML awal. Mode login situs dan login manual menggunakan konfigurasi URL tujuan di server, browser terisolasi, dan HTML setelah render. Dashboard tidak menampilkan kredensial.

Pencarian, pagination, penandaan pemeriksaan, dan ekspor bekerja pada tabel yang dipilih. Pemeriksaan merupakan catatan operator. Riwayat, hasil aktif, dan preferensi disimpan dalam sesi browser. Aplikasi belum memiliki akun pengguna atau penyimpanan database.

UI memakai aset lokal, label formulir, indikator status, navigasi keyboard, dan tata letak responsif. Pengujian browser mencakup lebar 1024, 768, dan 390 piksel, hasil sukses/gagal, ekspor, dan persistensi sesi.

Panduan menggunakan kartu langkah awal, perbandingan mode akses, konfigurasi yang dapat disalin, dan FAQ. Antarmuka menggunakan Bahasa Indonesia.
